Projets

Mes projets à Zone 01

La plupart des projets se font en groupe, avec Git et une correction par d'autres apprenants. Pour chacun, j'indique la partie que j'ai codée.

Terminé

Forum

Un forum web réalisé à quatre : inscription et connexion, posts par catégories, commentaires, likes et dislikes, filtres (date, catégorie, score) et barre de recherche, mot de passe oublié. Données dans SQLite, mots de passe hachés avec bcrypt, sessions par cookies, lancement avec Docker Compose.

  • Go
  • SQLite
  • bcrypt
  • Cookies
  • Docker
  • HTML/CSS
Voir le code sur GitHub (dépôt de l'équipe) ↗
Ma partieLe formulaire de création de post, le système de migrations de la base de données (scripts SQL versionnés lancés au démarrage), les commentaires (table, structure Go et formulaire) et le README du projet.Le défiFaire évoluer la base sans la recréer à chaque changement. Chaque script SQL est enregistré dans une table schema_migrations et n'est appliqué qu'une seule fois au démarrage.
Validé

Groupie Tracker

Un site qui lit une API JSON d'artistes et affiche leurs membres, dates et lieux de concerts. Deux extensions validées ensuite : geolocalization (carte des concerts avec Leaflet et OpenStreetMap) et visualizations (mise en page des données).

  • Go
  • API REST
  • JavaScript
  • Leaflet
  • Tests unitaires
Voir le code sur GitHub ↗
Ma partieTout le back-end en Go : appel et décodage de l'API JSON, modèles de données, handlers HTTP (dont la page artiste et la gestion des identifiants invalides) et tests unitaires.Le défiL'API sépare artistes, lieux, dates et relations dans quatre routes : une fonction Go par route, puis tout est assemblé sur la page artiste. Un identifiant invalide renvoie une page d'erreur 400 ou 404 au lieu de faire planter le serveur. Les données brutes (dates marquées « * », lieux comme new_hampshire-usa) sont nettoyées en Go avant l'affichage, avec des tests unitaires.
Validé

ASCII Art Web

Une application web qui transforme un texte en art ASCII selon trois polices. Extensions : stylize (interface), export-file (téléchargement du résultat) et dockerize (Dockerfile pour lancer l'application dans un conteneur).

  • Go
  • net/http
  • Templates
  • Docker
